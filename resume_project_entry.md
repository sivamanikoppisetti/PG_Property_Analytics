## PG Property Analytics | Microsoft Fabric, SQL & Power BI

- Built an end-to-end synthetic property analytics solution using Microsoft Fabric Warehouse, SQL, Power BI semantic modeling and DAX, covering occupancy, rental collections, outstanding rent, expenses and property performance.
- Designed a property-centered analytical model integrating property, tenant, bed, rent, expense, occupancy and date datasets, with reusable DAX measures for KPI reporting and interactive filtering.
- Developed an executive Power BI dashboard with KPI cards, revenue & expense analysis, occupancy by area, outstanding rent analysis and monthly collection trends for property-level performance monitoring.
- Implemented business-focused measures including occupancy %, rent collected, outstanding rent, net revenue, collection %, latest snapshot metrics and MoM performance.
